# [Cushion Display](https://modrinth.com/datapack/cushion-display)
Use cushion as item displays!

## ⚙️ Server side!
If you only install this datapack/mod on your server/LAN, it will work for everyone else without them needing to install it!

## 📖 Instructions:
- Shift-rightclick on a cushion while holding an item.
- To remove it, just break the cushion.

Items displayed on a cushion cannot be picked up and will never disappear.
The cushion will no longer be sitable.

Click to watch the demo

## ⤵️ Installation:
### Datapack:
Download the latest release and put the datapack  `.zip` file into the datapacks folder of your Minecraft world.
### Mod:
Download the latest release and put the mod  `.jar` file into the mods folder of your Minecraft game.
